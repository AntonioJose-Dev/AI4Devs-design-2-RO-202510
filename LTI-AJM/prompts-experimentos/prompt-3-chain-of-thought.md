Técnica: Chain-of-Thought Prompting

text
Actúa como Product Manager experto en ATS y metodologías ágiles.

# CONTEXTO:
Tengo documentado el sistema LTI (ATS con IA para startups tech) con todas sus funcionalidades, casos de uso y modelo de datos.

# TAREA (PASO A PASO):

**PASO 1: ANÁLISIS**
Primero, analiza las funcionalidades core del sistema LTI y determina:
- ¿Cuáles son las 3 funcionalidades más críticas para el MVP?
- ¿Qué flujos de usuario son prioritarios?
- ¿Qué features generan más valor para reclutadores vs hiring managers?

**PASO 2: PRIORIZACIÓN**
Luego, aplica el framework MoSCoW para clasificar las funcionalidades:
- Must Have (imprescindible para MVP)
- Should Have (importante pero no bloqueante)
- Could Have (deseable, mejora UX)
- Won't Have (fuera de scope v1)

**PASO 3: GENERACIÓN DE USER STORIES**
Finalmente, genera 10 User Stories completas usando esta plantilla:

**ID:** US-XXX
**Título:** [nombre corto]
**Como:** [tipo de usuario]
**Quiero:** [acción]
**Para:** [beneficio]
**Prioridad:** Alta/Media/Baja (justifica según MoSCoW)
**Criterios de aceptación:**
- [ ] Criterio 1
- [ ] Criterio 2
- [ ] Criterio 3
- [ ] Criterio 4
**Notas técnicas:** [stack, APIs, tablas BD]

**PASO 4: ORDENAMIENTO**
Ordena las User Stories en un backlog priorizado según:
1. Valor de negocio (ROI)
2. Riesgo técnico
3. Dependencias

---

Ejecuta los 4 pasos y entrega:
1. Tu análisis (PASO 1)
2. Clasificación MoSCoW (PASO 2)
3. Las 10 User Stories completas (PASO 3)
4. Backlog ordenado con justificación (PASO 4)
